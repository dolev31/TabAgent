TabAgent

Replace an LLM agent's closed‑set decisions with a cheap classifier trained from its own logs.

Tool shortlisting, routing, skill and application selection: learned from the agent's successful runs, decided in milliseconds, with the rest of the agent left unchanged.

How it works

Three phases, once per agent. Then milliseconds per decision.

TabAgent learns a closed-set decision from the agent's own successful trajectories and serves it from a tabular classifier. Data flows left to right; nothing else in the agent changes.

  1. Agent logs successful trajectories
  2. 1

    TabSchema

    Discovers features

    LLM agents analyze the trajectories, write and sandbox-test the extraction code, and a judge ensemble keeps the features that matter.

    TabSchema in detail
  3. 2

    TabSynth

    Augments the rows

    Deterministic, label-preserving paraphrases of the free-text state, where trajectories are scarce.

    TabSynth in detail
  4. 3

    TabHead

    Decides in milliseconds

    A CatBoost classifier scores every candidate of a decision in one pass, with an optional confidence gate.

    TabHead in detail
  5. Decision top-k tools, a label or a route
At inference agent step TabHead 2.682 ms decision unsure? defer to the LLM
