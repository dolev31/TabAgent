# Verdicts

- **correct**: the value is what the plan describes for this trajectory
- **incorrect**: the value is not what the plan describes for this trajectory, for example a flag that is true although the trajectory holds no such evidence (or false although it does), a count that is off, an identifier pattern that matched an unrelated word, or a category that does not fit the text
- **cannot_tell**: the trajectory does not show enough to decide (for example, the evidence would lie in a clipped part), or the plan is too vague to check

Judge the value, not whether the feature is useful. A missing value (null) is correct when the trajectory holds nothing to compute it from, and incorrect when it does.
