# Verdicts

- **valid**: the feature is computed as planned, from fields that exist in the schema, using only data before the classification suitable component
- **hallucinated_field**: the code reads a field that does not exist in the logging schema, or exists only in some trajectories by accident
- **plan_mismatch**: the code computes something materially different from the planned feature
- **missing**: the feature is not produced by the code
